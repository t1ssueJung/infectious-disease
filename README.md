# 우리 반 건강 탐험대

초등학교 3학년 2학기 과학 4단원 ‘감염병과 우리 생활’ 수업을 위한 웹앱입니다. 2022 개정 과학과 교육과정의 3~4학년군 ‘감염병과 건강한 생활’ 영역과 연계했습니다. 교과서마다 단원명·배열은 다를 수 있습니다.

## 가장 먼저 사용해 보기

1. 압축파일을 **완전히 풀어** 주세요.
2. `index.html`을 Chrome 또는 Edge에서 엽니다.
3. 감염병 카드, 퀴즈, 예방 실천 활동을 사용합니다.

별도 설치·빌드·회원가입·API 키가 필요 없습니다. 기본 학습과 퀴즈는 인터넷 없이 파일을 열어도 작동합니다. 자료 출처 링크는 인터넷이 필요합니다. 파일로 열었을 때 기록 저장 여부는 브라우저 설정에 따라 달라질 수 있습니다. 안정적인 공유·저장을 위해 GitHub Pages 사용을 권장합니다.

## GitHub Pages에 배포하기 — 브라우저로 업로드

이 자료는 배포용 파일입니다. 아직 GitHub 저장소나 공개 사이트를 생성한 상태는 아닙니다.

1. GitHub에 로그인한 뒤 오른쪽 위 **+ → New repository**를 선택합니다.
2. Repository name에 `infection-explorers` 등 원하는 영문 이름을 적고 **Public**으로 생성합니다. 무료 개인 계정의 일반적인 GitHub Pages 배포를 기준으로 설명했습니다.
3. **Add file → Upload files**를 선택합니다. 빈 저장소는 첫 화면의 **uploading an existing file** 링크를 사용할 수 있습니다.
4. 압축을 푼 `infection-explorers` 폴더 **안의 내용물**을 올립니다. 바깥 폴더나 ZIP 자체를 올리지 않습니다. 특히 `assets` 폴더도 함께 올려 주세요.
5. 저장소 최상위에서 `index.html`, `styles.css`, `data.js`, `app.js`, `assets` 폴더가 보이는지 확인하고 **Commit changes**를 누릅니다. `.nojekyll`은 포함되어 있으면 좋지만 이 앱에서는 빠져도 동작합니다.
6. 저장소 **Settings → Pages → Build and deployment**에서 **Source: Deploy from a branch**를 선택합니다.
7. **Branch: main**, **Folder: / (root)**를 선택하고 **Save**를 누릅니다. 기본 브랜치 이름이 다르면 실제 파일을 올린 브랜치를 고릅니다.
8. 배포가 끝나면 Pages 화면의 **Visit site**로 열어 봅니다. 저장소의 **Actions** 탭에서도 배포 진행 상태를 확인할 수 있습니다.
9. 주소는 보통 `https://사용자이름.github.io/저장소이름/`입니다. 이 주소를 학급에 공유합니다. GitHub 저장소 주소와 웹앱 주소는 다릅니다.

메뉴 명칭은 GitHub 화면 변경이나 계정 설정에 따라 달라질 수 있습니다. 공식 안내: [GitHub Pages 게시 원본 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

### 업로드 후 확인할 것

- 첫 화면에 그림과 카드 6개가 모두 나타나는지 확인합니다.
- 카드 하나를 열어 완료 도장을 찍고 새로고침 후 도장이 남는지 확인합니다.
- ‘도전! 퀴즈’에서 문제에 답하고 해설·결과 화면이 나오는지 확인합니다.
- 휴대전화에서도 같은 주소로 열어 봅니다.
- 하얀 화면/404: 저장소 최상위의 `index.html` 위치와 Pages의 브랜치·폴더 설정을 확인합니다.
- 디자인/그림이 안 보임: `styles.css`, `app.js`, `data.js`, `assets`가 `index.html`과 같은 폴더에 있는지 확인합니다. 파일명 대소문자도 같아야 합니다.
- 내용 수정 후 예전 화면이 보임: 배포 완료를 확인하고 강력 새로고침(Ctrl+Shift+R)을 해 봅니다.

## 학생용 기능

- **감염병 탐구**: 파상풍, 인플루엔자(독감), 일본뇌염, 감염성 결막염, 식중독, 회충증
- 각 감염병의 **원인·감염 과정, 특징, 건강 영향, 사회 안전 영향, 실제 유행/발생 사례, 예방법**
- 3학년이 읽기 쉬운 짧은 문장과 생활 속 표현, 감염병별 **낱말 뜻풀이**
- 토끼·곰·별 탐험대 캐릭터, 밝은 색의 둥근 카드와 큰 버튼
- 비교표와 감염 경로 비교, 친구와 나눌 토의 질문
- **총 24문항**: 감염병마다 원인 1, 특징/건강 1, 사회/발생 1, 예방 1
- 종합 12문항(감염병마다 2문항), 종합 24문항, 감염병별 4문항
- 문제 순서와 보기 순서 무작위, 정답·해설, 틀린 문제 재도전, 결과 인쇄
- 날짜별 예방 실천 표시, 건강 약속 저장, 실천 기록 인쇄
- 탐구 완료 도장, 큰 글씨, 모바일 화면, 키보드 조작 지원

## 수업 활용

화면 오른쪽 위 **선생님 안내**에서 성취기준 연계, 40분 수업 예시, 지도 시 고려 사항, 기록 초기화를 볼 수 있습니다.

| 성취기준 | 연계 활동 |
|---|---|
| [4과08-01] 감염병 사례·위험성 탐구 | 카드 탐구, 건강 영향과 실제 사례 읽기 |
| [4과08-02] 감염 과정·생활 습관·유행의 관계 | 감염 과정 비교, 사회 안전 토의 |
| [4과08-03] 예방 수칙 공유·실천 | 예방 퀴즈, 실천 표시, 건강 약속 |

표의 설명은 성취기준을 활동에 맞게 요약한 것입니다. 원문 확인 자료: [경기도교육청 2022 개정 교육과정 편성 안내, 인쇄 95쪽](https://www.goe.go.kr/resource/old/BBSMSTR_000000030136/BBS_202312210923589990.pdf).

감염병을 가진 학생을 찾거나 증상으로 진단하는 활동이 아닙니다. 누구나 아플 수 있으며, 환자나 특정 지역을 탓하지 않는 태도를 함께 지도해 주세요.

## 기록과 개인정보

- 이름, 학교, 반, 학생 번호, 건강 정보, 계정 정보를 수집하지 않습니다.
- 앱에 분석 도구, 광고, 외부 폰트, 외부 스크립트가 없습니다.
- 서버에 학습 기록을 보내지 않습니다. GitHub Pages 자체의 운영 로그 등은 호스팅 제공자의 정책에 따릅니다.
- `localStorage`의 `health-explorers-v1` 키에 완료 카드 ID, 당일 실천 ID, 실천 날짜, 건강 약속, 종합 퀴즈 최고 정답률, 큰 글씨 설정을 저장합니다.
- 현재 진행 중인 퀴즈의 답과 결과 복습 노트는 메모리에만 있어 새로고침하면 사라집니다. 최고 정답률은 종합 퀴즈를 끝냈을 때 저장하며, 재도전 점수는 최고 기록에 반영하지 않습니다.
- 다른 기기/브라우저와 동기화되지 않으며 교사용 학급 결과 수집 기능은 없습니다.
- 날짜는 학생 기기의 날짜 기준입니다. 당일 실천은 날짜가 바뀌고 실천 화면을 열거나 표시를 변경할 때 새로 시작합니다.
- 공용 기기에서 학생이 바뀌면 **선생님 안내 → 이 브라우저의 학습 기록 모두 지우기**를 사용합니다.
- 건강 약속 입력란에는 이름이나 건강 상태를 쓰지 않도록 안내합니다.

## 파일 구성과 수정 방법

```text
infection-explorers/
├── index.html          # 화면 구조, 제목
├── styles.css          # 색상·글씨·반응형·인쇄
├── cute.css            # 귀여운 캐릭터 분위기·화면 디자인
├── data.js             # 교사가 수정할 감염병 정보, 출처, 퀴즈
├── app.js              # 탐구·퀴즈·기록 기능
├── assets/
│   ├── badge.svg       # 직접 작성한 배지
│   ├── health-town.svg # 직접 작성한 마을 삽화
│   └── health-team.svg # 토끼·곰·별 건강 탐험대 삽화
├── README.md           # 배포·사용 안내
├── SOURCES.md          # 자료 출처와 내용 설계 근거
├── LICENSE.txt         # 직접 작성한 코드·자료 이용 안내
├── .gitignore
└── .nojekyll
```

`data.js`의 `diseases`에서 감염병 설명을 수정할 수 있습니다. `basicWords`에는 공통 낱말 뜻풀이가, 감염병별 `words`에는 그 카드의 낱말 뜻풀이가 있습니다. `questions`의 각 문항은 `id`(문항 번호), `disease`(감염병 ID), `category`(영역), `text`(질문), `options`(보기 배열), `answer`(정답 번호), `explanation`(해설)로 구성되어 있습니다. 정답 번호는 **0부터** 셉니다. 현재 앱은 감염병 6개, 각각 4문항을 기준으로 구성되어 있으므로 문항 수나 감염병 수를 바꾸려면 `app.js`의 출제·진행 표시도 함께 검토하세요.

수정한 파일을 같은 GitHub 저장소에 업로드하고 Commit하면 다시 배포됩니다. `.github` 설정이나 빌드 도구 없이 브랜치 배포만 사용합니다. 모든 앱 자산 경로가 상대 경로이므로 프로젝트 저장소의 하위 경로에서도 작동합니다.
